# Веб-админка

Создание шаблонов проверок, назначение визитов, просмотр результатов, дашборд.

Стек: React 18 + TypeScript + Vite. Подробности и TODO — в AGENTS.md (раздел «Admin»).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173, прокси /api -> localhost:8080
```

Бекенд должен быть запущен (`../backend && ./gradlew run`).
