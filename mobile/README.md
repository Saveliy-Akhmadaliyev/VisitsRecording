# Мобильное приложение (Android)

Приложение полевого сотрудника: список назначенных визитов, заполнение проверок
по шаблону офлайн, фото, отправка при появлении сети (offline-first).

Стек: Kotlin + Jetpack Compose, Room (локальная БД), WorkManager (фоновая
синхронизация), Ktor-клиент (тот же, что на беке). Схема БД — `идеи/entities_mobile.md`,
план — `идеи/roadmap_mobile.md` (этап 1 MVP).

## Запуск

1. Бекенд + Postgres + MinIO должны быть запущены (см. ../README.md).
2. Открыть проект в Android Studio (или `./gradlew assembleDebug`).
3. Эмулятор: приложение ходит на `http://10.0.2.2:8080` (localhost хост-машины).
   Реальное устройство: поменять `BASE_URL` в `net/Api.kt` на IP машины с беком.

При первом запуске нужно выбрать инспектора (DEV-заглушка — аутентификации
на беке пока нет).

## Что реализовано (этап 1, начало)

- Room: 5 таблиц по `entities_mobile.md` + статусы синхронизации
- Сеть: presign + sync (контракт `идеи/mobile_api.md`)
- `SyncRepository` + `SyncWorker`: фото -> S3, затем push/pull одним запросом,
  конфликты last-write-wins, CANCELLED с сервера удаляет визит локально
- Фото: системная камера (интент), сжатие до 1600px/JPEG 80%, `filesDir/pending_photos`
- UI: список визитов с вкладками и плашкой синка, детали с маршрутом,
  чек-лист (да/нет, 1–5, выбор, текст, проблема+комментарий, фото, автосохранение)
